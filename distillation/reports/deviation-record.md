## 6. 判定落差归因（基于 20 篇人工复核）

### 6.1 判高的机制：公式化完成度被计数型规则奖励

- 典型样本 `B6-ADV-002`（真 6.0 / 预评 8.5）：结构完整、连接词齐全、
  「This is mainly because → For example → As a result」三段式反复出现，
  但例证全是假设性泛例（"an employee may have to work longer hours"），两个主体段未提供新信息；
  计数型 TR/GRA 把「标记齐全」误当作「论证充分」。
- 典型样本 `B6-OP-006`（真 6.0 / 预评 8.5）：TTR 0.79、字面覆盖 0.81，词汇与结构表面分高；
  但开头直接复述题干（疑似套用题目原句），论点停留在「艺术减压、有助职业」的常识层。
- 结论：**「完整但泛化」是 6.0–6.5 的典型形态，必须用 L2 锚点比对才能与 7+ 区分**；
  单纯的特征计数会把这类文章推到 8+。

### 6.2 判低的机制：高分文刻意违反「字面覆盖 + 标记密度」假设

- 典型样本 `B9-OP-005`（真 9.0 / 预评 6.0）：关键概念全部改写（字面覆盖 0.39），
  引言即引入 harm principle 作为分析框架，几乎不用 because/for example；
  连接词密度仅 1.05/100 词——恰是 9.0 档的特征（全档中位 2.55）。
- 典型样本 `B9-REP-002`（真 9.0 / 预评 6.0）：报告类 9.0 用「Three things have shifted at once」
  组织因果，而非 what are the causes 的字面复述；覆盖 0.29 被误判为回应不足。
- 典型样本 `B9-DIS-004`（真 9.0 / 预评 6.5）：官方评语称其以「pessimists / optimists / decisive variable」
  三层框架重构题目；计数型规则只看到低连接词密度与低字面覆盖。
- 结论：**Band 8+ 的文本特征与 6–7 档相反**——改写题干、少用标记、低连接词密度；
  任何把这些指标当作正向证据的规则都会系统性判低高档。

### 6.3 官方措辞 → 操作化代理 → 落差 → L1 修订对照

| 官方措辞 | 本步操作化代理 | 观察到的落差 | L1 采用的修订 |
|---|---|---|---|
| addresses all parts | 题干实词字面覆盖率 | 8+ 档改写题干 → 覆盖率反而低，被误判未回应 | §0.2 覆盖率只作「低覆盖预警」；TR 用概念回应检查 |
| extends and supports main ideas | because/for example 标记计数 | 公式化 6.0 文被高估；标记少的 9.0 文被低估 | L1-TR-6.2 检查「例证后是否推进」；L1-TR-9.1 重构框架 |
| uses cohesive devices | 显性连接词密度与种类 | 连接词越多越像高分，但语料相关性为负（ρ=−0.36） | L1-CC-6.1 / 75.1；密度只作复检信号 |
| uses a variety of complex structures | 复杂句占比 / 从属结构密度 | 与总分几乎不相关（ρ≤0.11） | L1-GRA-7.2：不得按复杂句数量定档 |
| error-free | 语料级罕见词 / 正则扫描 | 抓不到中式搭配，且把主题专名当噪声 | L3 增加负迁移标签；GRA 以锚点比对为主 |

### 6.4 对 L1 的直接启示

1. 所有「数量型」特征必须配合至少一条「质量型」判别操作（如展开检查：解释后是否推进）；
2. 连接词密度只作为辅助信号，评分以段间语义推进检查为主；
3. 词表类信号只用于 LR 复检，不单独触发降档；
4. 半分档必须依靠「稳定性」判别（段落间波动、错误出现的分布），而非整体均值；
5. 计数型预评分与规则结论冲突时以规则与 L2 锚点为准（任务三 §1.5 的复检机制同理）。
