- **[CRIME-01] 观点：公共服务能否私有化取决于「质量是否可测量」——垃圾清运可以，监狱不行**（倾向：分领域差异化）
  - 展开：机制——可逐项验收的服务（街道、频次、清洁度）能激励承包商降本增效 → 反例——监狱的关键结果（再犯率、冲突化解）多年才能显现，合同只能奖励可计数指标（越狱、入住率、人均成本）→ 回扣——按「能不能被计数」决定私有化边界，而不是按意识形态。
  - 适用题型：adv-disadv / discussion
  - 来源样本：`B9-ADV-011`（9）
  - 高分搭配：`where quality is visible`、`what can be counted`、`occupancy and cost per place`

- **[CRIME-02] 观点：短期监禁对低级别财产犯罪产生三重破坏；社区刑罚只有在真正配资源时才成立**（倾向：有条件支持社区服刑）
  - 展开：机制——三个月刑期夺走工作、租约与家庭支撑，却碰不到成瘾、债务与住房问题 → 反例——无治疗配套的无偿劳动令不是刑罚，公众的不信任有事实基础 → 回扣——关键在于为社区方案配备治疗与监督资源，否则监狱看起来才是「负责任」的选择。
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-070`（9）
  - 高分搭配：`community disposals`、`underfunded alternatives`、`a criminal record`

- **[CRIME-03] 观点：网络诈骗的三个位移——身份信息常态化公开、尝试成本趋零、目标按便利而非财富选择**（倾向：个体只需「比下一个人更贵」）
  - 展开：机制——冒充所需信息散落在零售、雇主与社交网络 → 机制二——一条诈骗信息可零成本发给十万人，成功率万分之一即有利可图 → 回扣——个体防护的目标是提高攻击成本，而非追求「不可攻破」。
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-002`（9）
  - 高分搭配：`published as a matter of course`、`almost costless to attempt`、`more expensive to attack`

- **[CRIME-04] 观点：出狱再犯的根源是无地址与无工作，干预必须发生在释放之前**（倾向：释放前衔接）
  - 展开：机制——在押期间无法维持租约，释放即无固定地址 → 机制二——犯罪记录可披露，雇主有其他申请人时没有理由冒险 → 对策——释放前落实住房、保留培训名额或工作承诺。
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-004`（9）
  - 高分搭配：`no fixed address`、`the record is disclosable`、`housing arranged before release`

- **[CRIME-05] 观点：公共监控的争论是「安全收益 vs 被监视感」的交换，威慑效果与被侵犯感需同时计价**（倾向：收益大于代价，但需监管）
  - 展开：机制——摄像头让潜在犯罪者被记录、被追踪 → 反例——无授权观察造成持续被监视的压力，损害心理状态 → 回扣——制度需限定目的、保存期限与申诉渠道，才能让威慑收益成立。
  - 适用题型：adv-disadv / discussion
  - 来源样本：`B85-ADV-005`（8.5）
  - 高分搭配：`violates their privacy`、`deter potential offenders`、`mental well-being`

- **[CRIME-06] 观点：对低级别侵财犯罪，短期监禁既切断工作、租约与家庭支撑，又触及不到成瘾、债务与混乱住房，反而使下一次犯罪更可能发生**（倾向：反对）
  - 展开：机制——三个月刑期让人失去工作、租约与家庭支撑，出狱时只带回犯罪记录 → 例证方向——成瘾、债务与住房问题在十二周内根本无法处理 → 回扣——争论刑罚太重还是太轻偏离要害，用错工具的代价是再犯概率上升
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-070`（9）
  - 高分搭配：`low level`、`custody`、`deterrence`

- **[CRIME-07] 观点：社区刑罚只有在配足治疗与监督资源时才成立；罪与非罪的分类应按危害与刑罚能达成的目标，而不是按是否使用暴力**（倾向：条件性）
  - 展开：机制——没有治疗配套的无偿劳动令、超负荷的缓刑监督，会让替代方案失败得显而易见 → 反例——掏空养老金的诈骗不是暴力却危害巨大，酒馆外的斗殴虽是暴力却未必需要监禁 → 回扣——问题出在资源与分类标准，而不是社区刑罚的原理
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-070`（9）
  - 高分搭配：`probation`、`community`、`non violent`

- **[CRIME-08] 观点：网络诈骗激增源于三件事同时变化：冒充所需信息随处可得、作案成本几乎为零、跨境管辖让执法追不上**（倾向：中立）
  - 展开：机制——身份信息散落在零售商、雇主与社交网络之间，诈骗者一开始就拿到过去要花数周收集的材料 → 机制——一条诈骗信息可近乎零成本发给十万人，成功率万分之一依然有利可图 → 回扣——犯罪按产业规模运作，受害者按便利而非财富被挑选
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-002`（9）
  - 高分搭配：`impersonate`、`jurisdiction`、`laundered`

- **[CRIME-09] 观点：个人防护的关键是抬高攻击成本：双重验证、密码管理器，以及把「紧迫感」本身当作诈骗警报**（倾向：支持）
  - 展开：机制——双重验证让被窃密码从钥匙变成无用字符串，密码管理器阻断撞库连锁 → 机制——几乎所有成功诈骗都要求受害者在思考之前行动 → 回扣——目标不是不可攻破，而是比名单上的下一个人更难攻击
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-002`（9）
  - 高分搭配：`two factor`、`password`、`urgency`

- **[CRIME-10] 观点：许多年轻人出狱时没有固定住址、没有工作、没有资历，再犯在这种处境下是阻力最小的路径，而非道德选择**（倾向：中立）
  - 展开：机制——在押期间无法维持租约，释放后没有固定住址 → 机制——犯罪记录可披露，有其他申请人的雇主没有理由冒险 → 回扣——剩下的只有原来的社区与熟人，再犯不是道德选择的复归
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-004`（9）
  - 高分搭配：`disclosable`、`qualification`、`tenancy`

- **[CRIME-11] 观点：降低再犯的干预必须发生在释放之前：提前安排住房、保留培训名额或岗位、配一名不更换的联络人、限制轻微定罪的披露期限**（倾向：支持）
  - 展开：机制——释放前落实住房与岗位，过渡期才不至于断裂 → 机制——固定的个案联络人让支持关系跨越出狱这个节点 → 回扣——这些措施平淡而不受欢迎，正因为它们看起来像对犯罪的奖励
  - 适用题型：report / two-part
  - 来源样本：`B9-REP-004`（9）
  - 高分搭配：`housing`、`release`、`declared`

- **[CRIME-12] 观点：犯罪记录会让雇主负面看待前囚犯，使其难以获得稳定工作与稳定收入，从而回到非法活动**（倾向：中立）
  - 展开：机制——雇主面对其他申请人时不愿承担雇用风险 → 机制——缺乏专业资历或实用技能使就业机会更窄 → 回扣——收入不稳定直接提高再次犯罪的可能性
  - 适用题型：report / two-part
  - 来源样本：`B8-REP-015`（8）、`B8-REP-014`（8）
  - 高分搭配：`qualifications`、`employment`、`re offending`

- **[CRIME-13] 观点：监狱环境本身会加剧再犯：囚犯之间交换作案信息，出狱后又缺少谋生技能与就业机会**（倾向：中立）
  - 展开：机制——监狱把罪犯集中在一起，他们在服刑期间交换信息甚至策划犯罪 → 机制——贫穷、未受教育、缺乏维持工作的技能 → 回扣——犯罪记录叠加就业歧视，形成恶性循环
  - 适用题型：report / two-part
  - 来源样本：`B8-REP-014`（8）、`B8-OP-032`（8）
  - 高分搭配：`inmates`、`vocational`、`offenders`

- **[CRIME-14] 观点：应对再犯应把改造放在惩罚之前：狱内职业培训为出狱后的生活做准备，社区服务则避免罪犯与囚犯为伍**（倾向：支持）
  - 展开：措施——监狱开展职业培训，让囚犯学习计算机编程、汽车维修与平面设计等实用技能 → 措施——社区服务让罪犯帮助社会、成为社区中有用的人 → 回扣——改造与重返社会优先于惩罚本身
  - 适用题型：report / two-part
  - 来源样本：`B8-REP-013`（8）、`B8-REP-014`（8）
  - 高分搭配：`rehabilitation`、`supervision`、`vocational`

- **[CRIME-15] 观点：在功能失调家庭或贫困社区长大、并持续与犯罪者交往，会让犯罪行为正常化，使人难以转向守法生活**（倾向：中立）
  - 展开：机制——成长环境使人从小就暴露于暴力、药物滥用与反社会行为 → 机制——出狱后继续与犯罪者交往，承受重回非法活动的巨大压力 → 回扣——守法生活方式难以建立，因为环境把犯罪变成了常态
  - 适用题型：report / two-part
  - 来源样本：`B8-REP-013`（8）
  - 高分搭配：`dysfunctional`、`normalised`、`law abiding`

- **[CRIME-16] 观点：犯罪率上升的主要经济根源是缺乏稳定就业与社会不平等扩大**（倾向：中立）
  - 展开：机制——无法赚取足够收入时，人们可能以非法活动满足基本需求 → 机制——社会不平等让被排除在经济机会之外的人产生挫败与怨恨 → 回扣——犯罪行为根植于经济困难与前景受限
  - 适用题型：report / two-part
  - 来源样本：`B8-REP-003`（8）
  - 高分搭配：`unemployment`、`inequality`、`hardship`

- **[CRIME-17] 观点：有效的预防是一组组合：教育投资与职业培训提升就业前景，经济援助与咨询服务帮助弱势者做出守法选择**（倾向：支持）
  - 展开：措施——政府投资教育与职业培训，让人获得实用技能、改善就业前景 → 措施——资金援助与咨询服务为弱势个体提供支持 → 回扣——经济机会与社会支持的组合才是降低犯罪最有效的策略
  - 适用题型：report
  - 来源样本：`B8-REP-003`（8）
  - 高分搭配：`vocational`、`counselling`、`prospects`

- **[CRIME-18] 观点：监禁只能在短期保护社会，常常变成「旋转门」；教育才是针对犯罪根源的长期方案**（倾向：支持）
  - 展开：机制——囚犯出狱时技能、知识与支持都没有改善，还可能接触暴力、心理问题与犯罪网络 → 对照——教育为高风险年轻人提供希望、目标与机会，狱内教育也能降低再犯率 → 回扣——挪威等以改造与教育为主的国家犯罪与再犯率持续偏低
  - 适用题型：opinion
  - 来源样本：`B8-OP-032`（8）
  - 高分搭配：`reoffending`、`incarcerated`、`disadvantaged`

- **[CRIME-19] 观点：技术既能加强犯罪预防与侦查，也可能被罪犯滥用并催生新型犯罪；但技术使用的门槛使整体影响偏向犯罪率下降**（倾向：条件性）
  - 展开：机制——监控摄像头、人脸识别与家庭安防让罪犯更难不被发现 → 反例——技术可能落入罪犯之手，个人敏感信息也可能被出售或泄露 → 回扣——多数罪犯教育程度较低、沿用旧手段，而执法部门对现代技术掌握得更好
  - 适用题型：opinion
  - 来源样本：`B9-OP-103`（9）、`B8-OP-010`（8）
  - 高分搭配：`surveillance`、`cybercrime`、`recognition`

- **[CRIME-20] 观点：公共场所监控以隐私为代价：未经许可的观察、持续被监视的心理压力，以及数据泄露的风险**（倾向：中立）
  - 展开：机制——监控设备未经许可观察个人，构成对隐私的侵犯 → 机制——公众感到自由减少、持续被当局监视，压力上升并损害心理健康 → 回扣——缺乏透明有效的监督机制时，数据还可能被相关机构用于非法或不道德目的
  - 适用题型：adv-disadv / discussion
  - 来源样本：`B85-ADV-005`（8.5）
  - 高分搭配：`surveillance`、`privacy`、`leakage`

- **[CRIME-21] 观点：监控的收益在于威慑潜在犯罪者、为执法机构提供视频证据并节省警力，从而把资源转投其他公共服务**（倾向：支持）
  - 展开：机制——威慑让潜在犯罪者不敢作案，犯罪率下降、社区更安全 → 机制——视频证据帮助破案，提高执法效率、减少所需警力 → 回扣——节省下来的经费可以重新分配到基础设施与公共服务

- **[CRIME-22] 观点：毒品合法化会减少为获取毒品而实施的犯罪、释放警力并带来税收，但同时可能让吸毒正常化、减少学校警示并推高成瘾与过量死亡**（倾向：条件性）

- **[CRIME-23] 观点：交通安全不能只靠严罚：处罚能威慑并减少重复违章，但道路照明等基础设施与智能交通技术同样关键**（倾向：条件性）
  - 展开：机制——对驾驶者的处罚形成威慑、减少重复违法 → 机制——改善照明使道路更安全，智能红绿灯与测速摄像头降低碰撞率 → 回扣——基础设施与先进交通技术的投入能带来更安全的驾驶环境
