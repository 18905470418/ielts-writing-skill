- **[CUL-01] 观点：文物归还的核心是「获取方式」，而不是情感化的遗产叙事；「保存能力」抗辩已被事实淘汰**（倾向：支持归还）
  - 展开：机制——大量文物在军事占领或无权政府下流出，那时的「许可」不是许可 → 反例——五十年前部分追索国确实缺乏恒温库与修复人员 → 回扣——多国已建成国际标准机构，实证性抗辩已转为习惯性拖延。
  - 适用题型：discussion / opinion
  - 来源样本：`B9-DIS-012`（9）
  - 高分搭配：`how the objects were obtained`、`climate-controlled storage`、`full international standard`

- **[CUL-02] 观点：传统手工艺的对手是机器而非同行；「保存」要保存的是活在手上的知识**（倾向：支持活态传承）
  - 展开：机制——工厂复制品以零头价格满足大多数买家 → 反例——把织机放进博物馆只保存了说明牌，真正的地方性知识（陶土在特定窑中的表现、木材含水的手感）只存在于从业者手中 → 回扣——政策应补贴实践场景与市场，而非只做展陈。
  - 适用题型：two-part / report
  - 来源样本：`B9-TQ-005`（9）
  - 高分搭配：`competes with a machine`、`lives only in the hands of people who practise it`、`luxury market`

- **[CUL-03] 观点：音乐作为「通用语言」的机制是情绪共振——相同和声触发相似情绪，形成共享纽带**（倾向：支持跨文化连接）
  - 展开：机制——音乐唤起难以言说的情绪（joy/empathy/nostalgia）→ 机制二——合作演奏（互换乐器）促进跨文化协作 → 回扣——音乐教育与交流项目的价值在情绪层面的连接，而非技能本身。
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-095`（9）
  - 高分搭配：`universal language`、`joy`、`empathy or nostalgia`、`shared bond`

- **[CUL-04] 观点：外语学习的长期价值是「理解所有语言如何运作」的迁移能力**（倾向：支持）
  - 展开：机制——学习一门语言获得对语言结构的元认知 → 例证方向——即使不常出国，这种知识在任何语言环境都能迁移 → 回扣——把外语只当旅行工具会低估其认知与职业回报。
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-040`（9）
  - 高分搭配：`how all languages work`、`go further than`、`the ability to use it`

- **[CUL-05] 观点：数字化让艺术「可检索、可注释」，但实物体验的笔触与临场感不可复制**（倾向：两者互补）
  - 展开：机制——线上可按类别、年代、艺术家排序并附专家解读 → 反例——屏幕几乎无法呈现笔触与质感，现场感无法替代 → 回扣——博物馆的价值转向「体验与情境」，数字平台承担普及与预习。
  - 适用题型：opinion / discussion
  - 来源样本：`B9-OP-089`（9）
  - 高分搭配：`hardly recognized on the computer screen`、`sorted by category`、`insightful explanations`

- **[CUL-06] 观点：文物归还争议的核心不是情感层面的遗产归属，而是文物取得方式的正当性；以受赠国当年缺乏保管能力为由的拒绝已随事实改变而失效。**（倾向：支持）
  - 展开：争议焦点在取得方式 → 许多文物在军事占领或本地人无从选择的行政下流失，当时的许可不构成真许可 → 五十年后多国已建成达国际标准的馆藏与修复能力，经验性理由应随事实变化而放弃 → 普遍性收藏的价值可通过长期互借、联合策展与共享修复保留，归还诉求不因保存争议而消解
  - 适用题型：discussion
  - 来源样本：`B9-DIS-012`（9）
  - 高分搭配：`military occupation`、`climate controlled storage`、`trained conservators`、`jointly curated exhibitions`、`shared conservation`

- **[CUL-07] 观点：传统手工艺衰亡并非因为不再受欣赏，而是机器量产与廉价替代品让手艺人失去营生；保护它应让技艺作为可谋生的行业存续，而非进入博物馆展柜。**（倾向：中立）
  - 展开：手工品与机器竞争而非与其他手艺人竞争 → 工厂以极低价格供应足够接近的替代品，手工品退居小众且善变的奢侈品市场 → 低薪随师学艺只在能换取稳定生计时才划算，年轻人转投他处是理性计算 → 关键知识只活在实践者手上，织机配标签的展陈保存极少；为学徒付薪、把公共工程合同交给传统作坊，才能让手艺以工作行业延续
  - 适用题型：two-part
  - 来源样本：`B9-TQ-005`（9）
  - 高分搭配：`luxury market`、`village weaver`、`paying apprentices`、`public contracts`、`traditional methods`

- **[CUL-08] 观点：在许多人仍处贫困的世界上，艺术品以天价易手令人难以接受：同等资金足以改变多家慈善机构的工作并直接挽救生命；但贪婪与艺术品作为投资品的属性使这种现状难以改变。**（倾向：反对）
  - 展开：一幅作品可达上亿美元成交 → 一笔画款即可重塑慈善机构的救助能力，药品、食物与住所可直接救命 → 由此视角，艺术市场显得有失体面 → 但有能力支付者通常不愿放弃财富，艺术品又被持有后转售获利，现实中难以改变
  - 适用题型：opinion
  - 来源样本：`B9-OP-038`（9）
  - 高分搭配：`pieces of art`、`enormous sums`、`human greed`、`resold at a profit`

- **[CUL-09] 观点：学习外语的价值远超旅行或商务中的零散使用：它帮助人们理解语言的运作方式、开放对其他文化的欣赏，并提升一般认知能力。**（倾向：支持）
  - 展开：反对者以多数人很少出国、语言不通为由判定投入低效 → 但学一门语言能让人理解所有语言如何运作 → 打开对其他文化、观点与信仰体系的理解 → 在全球化下减少冲突、促进包容，并训练认知能力
  - 适用题型：opinion
  - 来源样本：`B9-OP-040`（9）
  - 高分搭配：`foreign language`、`cognitive skills`、`language teachers`、`belief systems`

- **[CUL-10] 观点：博物馆与美术馆提供屏幕无法复制的感官与情感体验：笔触、材质与临场感带来独特的灵感时刻，尽管数字访问确实更便利。**（倾向：支持）
  - 展开：数字设备让艺术品触手可及 → 屏幕上难以辨认的笔触与细节在现场才显出生动，观者仿佛置身画中场景 → 这种刺激体验是数字屏幕无法达到的 → 但电脑让艺术信息可按类别、年代与作者检索，专家讲解随处可得，场馆的重要性确有被削弱的压力
  - 适用题型：opinion
  - 来源样本：`B9-OP-089`（9）
  - 高分搭配：`art galleries`、`computer screen`、`digital screen`、`historical paintings and sculptures`

- **[CUL-11] 观点：音乐能跨越语言与文化建立情感纽带，也能联结不同代际：共通的情绪反应在演出与节庆中把素不相识的人连接起来，传统歌曲则让年轻人理解长辈的心态。**（倾向：支持）
  - 展开：音乐被称为通用语言，能唤起难以言说的情绪 → 同一和声引发相似情绪反应，形成共享纽带 → 音乐节与演唱会中人们忽略国籍差异、共享情绪与兴奋 → 传统婚礼与家庭聚会中的经典歌曲让年轻一代接触古典音乐，增进相互尊重

  - 高分搭配：`universal language`、`shared bond`、`cultural boundaries`、`mutual respect`

- **[CUL-12] 观点：音乐并非总是“人类的通用语言”：一些国家用音乐塑造忠诚、维持统治，公民连接触多元音乐的自由都被剥夺。**（倾向：条件性）
  - 展开：音乐可被权力用于让民众忠诚 → 朝鲜只允许歌颂独裁者的音乐，创作其他类型者面临惩罚 → 公民不谈歌剧或音乐剧、缺少自由 → 这类社会并未共享人类语言，是悲剧性的例外

- **[CUL-13] 观点：人们研究住宅历史，出于好奇与消除不确定感、以及维护房产价值（古董、重要年代与结构完整性）的需要；口述与档案材料提供了可行途径。**（倾向：中立）
  - 展开：人类对周遭好奇、想避免不安 → 房主需评估结构完整性以妥善修复、保住房产价值 → 长期居民与前业主的口述提供真实见闻 → 旧报刊、地方档案、地契与人口普查数据让研究者可查证

- **[CUL-16] 观点：反对对外国游客收取更高票价：旅游收入支撑餐饮、住宿、交通等行业的发展与就业，政府税收可反哺文化遗产保护；不公平的价格还会把游客推向别国。**（倾向：反对）
  - 展开：支持差别定价者称景点由税收资助、本地人理应免费或低价 → 但外国游客带动旅游业及相关行业发展与薪资增长 → 政府税收可投入文化遗产的保护，形成良性循环 → 差别对待会削弱到访意愿，友好政策才能吸引国际游客

- **[CUL-17] 观点：保留传统生活方式具有重要价值：维系国家认同与文化多样性的自豪感，连接祖辈、缩小代际差距，并通过节庆仪式增强社会纽带与归属感；传承可依靠学校、家庭与社区协作。**（倾向：支持）
  - 展开：传统实践维系国家认同与文化自豪 → 后代在活动中与祖先相连、代际隔阂收窄 → 农业仪式等知识提醒耕作时令，避免技艺与智慧流失 → 节庆与社区活动把人们聚在一起；学校用可视化讲解与课外实践、家长带孩子观看传统表演，共同防止文化流失

- **[CUL-18] 观点：衣着趋同削弱全球文化多样性：人们难以感受与根源的联系、易忽视祖辈的贡献，少数族群还可能因人口外流而消失；但它也带来跨国的团结感与更低廉的成衣。**（倾向：中立）
  - 展开：趋同的代价：无法感受与根源的联系、忽视祖先的文化贡献、地区自豪感下降 → 人口流向城市，少数族群可能萎缩乃至消失 → 但共同穿着让人与世界各地的人形成一体感、愿意相互支持 → 成衣自动量产，比手工传统服饰更快更便宜

- **[CUL-19] 观点：博物馆收取门票利弊并存：收费抑制参观、尤其使穷人难以获取知识，也可能因客源流失而损害博物馆；但门票收入支持运营开销并改善展陈。**（倾向：中立）
  - 展开：票价让部分人特别是低收入者放弃参观 → 市民失去学习历史、科学、艺术的机会，博物馆的教育目标落空 → 但收费为人员、设备与水电等开销提供资金 → 收入可用于更新展陈、提升管理，售票博物馆常反而更好

- **[CUL-20] 观点：与看电视相比，阅读更有助于培养想象力与语言能力：文字迫使读者自行构建画面，电视则代劳；阅读还最利于扩充词汇与句式。**（倾向：支持）
  - 展开：书本常无插图，读者需用想象力补全场景 → 奇幻小说中的神话生物只能由读者在脑内成形，电视却把角色与场景都做好 → 阅读打印文本让人掌握拼写、从语境推定词义 → 电视画面分散注意力、缺少字幕时拼写不明，书籍对语言学习者更有效
