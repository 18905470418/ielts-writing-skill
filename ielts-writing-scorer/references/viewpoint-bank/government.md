# L5 观点库 · 政府与公共政策（GOV）

> 条目 25 条（v1 迁移 5 + v2 新增 20）；
> 来源：训练集 8+ 样本为主；薄主题含 7.5 补充并逐条标注；本主题 8+ 标签样本 17 篇，
> L5 引用覆盖 100%（17 个不同来源）。

- **[GOV-01] 观点：免费公交的门槛不是票价而是班次与可靠性；取消票价可能挤占改善服务的资金**（倾向：有条件支持）
  - 展开：机制——票价对低收入者是硬约束（累退）→ 反例——真正把人留在车里的是时间与可靠性，四十分钟一班的免费公交仍是四十分钟一班 → 回扣——若预算不变，政策是在「更便宜的票」与「更好的网络」之间做选择。
  - 适用题型：adv-disadv / opinion
  - 来源样本：`B9-ADV-027`（9）
  - 高分搭配：`fares are regressive`、`reliability`、`fare revenue`

- **[GOV-02] 观点：迁都/外迁政府机构的价值在区域均衡与「政策制定者接触现实」，成本主要为一次性**（倾向：利大于弊）
  - 展开：机制——首都吸走全国专业岗位，外迁把就业与消费带入衰退城镇 → 机制二——官员生活在政策对象中间，减少「只对首都有意义」的规则 → 反例——新建筑与人才流失是一次性成本 → 回扣——长期均衡收益大于过渡成本。
  - 适用题型：adv-disadv / discussion
  - 来源样本：`B9-ADV-029`（9）
  - 高分搭配：`drains talent`、`one-off losses`、`permanent drain`

- **[GOV-03] 观点：预防性医疗的经济性确定，但受益者不可命名，导致政治激励偏向治疗**（倾向：制度上保护预防预算）
  - 展开：机制——疫苗/筛查成本远低于替代的治疗 → 反例——被救的人不知道自己被救，而治疗总有病床与家属作为可见证据 → 回扣——需要独立的长期预算与评估机制，打破「可命名偏好」。
  - 适用题型：opinion / report
  - 来源样本：`B9-OP-014`（9）
  - 高分搭配：`its beneficiaries cannot be named`、`treatment-only system`、`the economics are not in doubt`

- **[GOV-04] 观点：评价大型赛事投入要看「什么留下来」：交通与防洪是资产，一次性场馆是负债**（倾向：反对纪念碑式建设）
  - 展开：机制——为场馆修的地铁服务通勤五十年 → 反例——为一个 fortnight 建的田径场无法改作他用且维护昂贵 → 机制二——激励结构奖励「雄心」而无人为维护账单负责 → 回扣——复用现有场地与临时设施是可行替代。
  - 适用题型：opinion / report
  - 来源样本：`B9-OP-045`（9）
  - 高分搭配：`consider what survives`、`sized for one fortnight`、`a fraction of the cost`

- **[GOV-05] 观点：住房与环境的折中是「向上建」，但用成本压力压缩居住面积会制造不平等**（倾向：垂直扩张 + 保障供给）
  - 展开：机制——减小建筑占地、增加高度可同时供房与护地 → 反例——提高建房成本把压力转给低收入者，结果是居住标准与冲突 → 回扣——政策应扩大供给与公共交通配套，而不是把成本当调节器。
  - 适用题型：opinion / report
  - 来源样本：`B9-OP-032`（9）
  - 高分搭配：`building footprints`、`unequal living standards`、`plausible solution`

- **[GOV-06] 观点：支持者认为公交票价是累退负担：月票对律师微不足道、对清洁工却相当沉重；取消票价能直接改善低收入者的出行与就业可及性，并省去售票、检票等行政成本。**（倾向：支持）
  - 展开：票价按收入占比递减 → 低收入者的通勤成本决定哪些工作在其可及范围内 → 免费乘车兼具公平与节省售票、检票成本的双重收益
  - 适用题型：adv-disadv
  - 来源样本：`B9-ADV-027`（9）
  - 高分搭配：`public transport`、`free travel`、`fare revenue`

- **[GOV-07] 观点：反对者指出，把人们留在车里的是时间、可靠性与班次不足，而非票价；免费化主要回报既有乘客，还会占用本可用于加密班次的票款收入。**（倾向：反对）
  - 展开：出行方式由时间、可靠性与服务时段决定 → 40 分钟一班的免费巴士仍无法吸引车主 → 免费政策换来的是更便宜的票而非更好的网络
  - 适用题型：adv-disadv
  - 来源样本：`B9-ADV-027`（9）
  - 高分搭配：`fare revenue`、`public transport`、`better network`

- **[GOV-08] 观点：部委整体外迁可为失去主业的城镇带来薪资与配套岗位，让官员贴近政策影响的人群，并缓解首都昂贵的住房与拥挤的通勤。**（倾向：支持）
  - 展开：首都集中全国大部分稳定专业岗位，抽走各地人才 → 数千人规模的部委迁入带来律师、餐饮与承包商等岗位 → 首都住房与铁路压力同步下降
  - 适用题型：adv-disadv
  - 来源样本：`B9-ADV-029`（9）
  - 高分搭配：`professional jobs`、`expensive housing`、`crowded trains`

- **[GOV-09] 观点：搬迁的新建成本与资深员工流失是一次性损失；若只把事务性工作迁出、高层职位仍留在部长身边，就会形成花钱而目的落空的“空心搬迁”。**（倾向：条件性）
  - 展开：新建筑要花钱、受家庭牵绊的资深员工不愿搬迁 → 一次性损失可随时间弥补，而机会集中是永久的流失 → 只迁流程工作则只剩成本没有收益
  - 适用题型：adv-disadv
  - 来源样本：`B9-ADV-029`（9）
  - 高分搭配：`hollow move`、`senior posts`、`processing work`

- **[GOV-10] 观点：预防医疗更具成本效益：疫苗、筛查与控烟的成本只是其所替代治疗的一小部分，且节省会在一生中不断累积。**（倾向：支持）
  - 展开：预防成本远低于其所替代的治疗并持续复利 → 预防在疾病变得昂贵且难治之前先触达人群 → 因此卫生预算应向预防倾斜
  - 适用题型：opinion
  - 来源样本：`B9-OP-014`（9）
  - 高分搭配：`vaccination programme`、`screening service`、`reduce smoking`

- **[GOV-11] 观点：预防的政治弱点在于受益人无法具名——未患病者不会知道自己曾受益，而治疗总有病床与家庭可被指认，这使预防在预算竞争中处于下风。**（倾向：条件性）
  - 展开：筛查在无人知晓中挽救生命 → 治疗总有名有姓的面孔出现在报纸上 → 社会也难为统计收益放弃可指认的病人，因此只能大幅倾斜而非“永远优先”
  - 适用题型：opinion
  - 来源样本：`B9-OP-014`（9）
  - 高分搭配：`statistical benefit`、`named patient`

- **[GOV-12] 观点：赛事开支是否浪费取决于它留下什么：为场馆修的轨道延长线与防洪工程可服务数十年，按两周赛程尺寸建造的体育场则闲置且维护昂贵；激励结构还不断奖励这种“纪念碑”。**（倾向：条件性）
  - 展开：同一笔预算既可能建成长期资产，也可能建成纪念碑 → 地铁延伸与防洪设施长期服务市民，超大体育场赛后难用 → 申办看雄心、官员先于维护账单离任，浪费因此是自选动作
  - 适用题型：opinion
  - 来源样本：`B9-OP-045`（9）
  - 高分搭配：`metro extension`、`flood defence`、`maintenance bills`

- **[GOV-13] 观点：对生活垃圾设定上限并配合收费可以推动家庭减量，并促使人们更留意哪些物品可以回收或堆肥。**（倾向：支持）
  - 展开：家庭垃圾产量惊人、难以管理 → 对超限家庭征税形成直接经济激励 → 家庭减少垃圾并提高回收、堆肥意识
  - 适用题型：opinion
  - 来源样本：`B9-OP-013`（9）
  - 高分搭配：`taxing households`、`recycled or composted`

- **[GOV-14] 观点：限废难以奏效：垃圾量由生活方式与所购商品决定，家庭仍想继续购买；征税既招致对常规账单已感吃力的家庭不满，还可能诱发乱丢与倾倒。**（倾向：反对）
  - 展开：垃圾是消费行为的产物 → 征税引发怨恨，并促使人们把多余垃圾丢到不被发现的地方 → 环境反而受损，教育、回收与堆肥比硬性限额更可行
  - 适用题型：opinion
  - 来源样本：`B9-OP-013`（9）
  - 高分搭配：`usual bills`、`littering and dumping`、`produce less waste`

- **[GOV-15] 观点：减少建筑占地、向高处要空间，被视为同时容纳增长人口与保护环境的有效方案。**（倾向：支持）
  - 展开：住房供给是政府的关键任务 → 缩小建筑占地、增加楼高可减少对环境的破坏 → 但高楼会减少街道日照、提高居住密度，并非没有代价
  - 适用题型：opinion
  - 来源样本：`B9-OP-032`（9）
  - 高分搭配：`building footprints`、`increasing the height`

- **[GOV-16] 观点：通过提高建造成本迫使人们住进更小面积并不可行：影响按财富分布不均，会拉大居住标准差距并引发冲突，高层住宅还会减少街道日照。**（倾向：反对）
  - 展开：抬高成本把人们压进更小住宅 → 影响按财富不均等分布 → 居住不平等与冲突随之而来，因此不是可信的解决方案
  - 适用题型：opinion
  - 来源样本：`B9-OP-032`（9）
  - 高分搭配：`increase building costs`、`unequal living standards`

- **[GOV-17] 观点：纳税之外，公民还应承担志愿、守法、捐赠等义务；若有人制造危险处境或违反法律，国家还需额外支出，说明仅纳税并不足以尽到社会责任。**（倾向：支持）
  - 展开：税收改善医疗、教育与公共品 → 但志愿者、守法者与捐赠者让社会运转得更好 → 违法行为迫使国家追加投入，说明责任不止于纳税
  - 适用题型：discussion
  - 来源样本：`B9-DIS-024`（9）
  - 高分搭配：`public goods and services`、`obeying laws`

- **[GOV-18] 观点：公共交通的优势与代价并存：其运力远大于私家车，可显著减少高峰拥堵与交通污染；但修建地下网络需要大量土地与专业工程人员，管理不善会让政府背上债务。**（倾向：条件性）
  - 展开：地铁单次载客量远超私家车 → 更多人改乘可削减高峰车流与尾气 → 但地下网络建设需要土地、工程师与完整配套，管理不善则使政府负债
  - 适用题型：adv-disadv
  - 来源样本：`B85-ADV-041`（8.5）
  - 高分搭配：`traffic congestion`、`underground network`

- **[GOV-19] 观点：优先铁路的理由在于效率、成本与环境：货运列车能以更少趟次长途运输大宗货物，电动列车运营维护更便宜，铁路人均碳排放约为私家车的六分之一，而新建道路会诱发额外车流。**（倾向：支持）
  - 展开：铁路大运量、长距离成本更低 → 电气化列车运营与维护更省钱 → 人均碳排放远低于公路，且扩建道路诱发需求而非缓解拥堵
  - 适用题型：opinion
  - 来源样本：`B85-OP-011`（8.5）、`B8-OP-005`（8）、`B85-OP-013`（8.5）
  - 高分搭配：`high speed rail`、`railway infrastructure`、`carbon emissions`

- **[GOV-20] 观点：对外援助既是道德义务也有长期回报：印度在2020年疫情期间向各国提供防护装备赢得善意与友谊，中国的“一带一路”让沿线国家获得此前缺乏的基础设施并促进贸易。**（倾向：支持）
  - 展开：各国在危机中相互援助符合道德准则 → 援助提升双边关系与国际声誉 → 贸易与需求增长让援助国经济同步受益
  - 适用题型：opinion
  - 来源样本：`B85-OP-027`（8.5）
  - 高分搭配：`bilateral relationship`、`trade relations`

- **[GOV-21] 观点：环境治理需要政府与个人共同担责：政府掌握强制资源与执法权，可投资环保项目并立法（如英国2008年禁止砍伐密林）；个人也应减少传统能源消耗、抵制以濒危物种制成的商品。**（倾向：条件性）
  - 展开：政府有预算与执法权（禁伐、绿色政策）→ 工业与电站造成大部分污染，需要监管与投资 → 个人消费同样影响栖息地，双方须共同行动
  - 适用题型：opinion
  - 来源样本：`B85-OP-028`（8.5）
  - 高分搭配：`environmental problems`、`logging operations`

- **[GOV-22] 观点：与其扩建道路，不如投资公共交通：高容量公交一次可载更多乘客（悉尼铁路每列车约减少1000辆汽车），转向公交能缓解城市拥堵并减少碳排放与空气污染。**（倾向：支持）
  - 展开：公交单次载客量远超小汽车 → 私转公的模式转移可大幅缓解城市拥堵 → 同时减少碳排放、改善空气与气候
  - 适用题型：opinion
  - 来源样本：`B85-OP-074`（8.5）
  - 高分搭配：`public transport`、`public transit`、`carbon emissions`

- **[GOV-23] 观点：太空预算应转投公共服务：学校与医院是社会运转的基础，把星际探测资金转投教育、公共卫生等公共软基础设施可带来即期与长期收益，而天文任务难以回应公众在医疗与教育上的紧迫需求。**（倾向：支持）
  - 展开：数十亿太空开支挤占教育与公共卫生资金 → 低收入国家教室拥挤、师资短缺显示公共品优先级更高 → 天文任务不解决疾病与贫困等日常问题
  - 适用题型：opinion
  - 来源样本：`B85-OP-082`（8.5）
  - 高分搭配：`public health`、`public funds`、`public money`

- **[GOV-24] 观点：大规模监控即使以安全为名也威胁自由社会：通信可能被监控会引发自我审查，海量数据让安全部门漏掉真正的威胁；应由独立司法授权、基于合理依据的定向监控取而代之。**（倾向：反对）
  - 展开：监控的存在本身引发自我审查，侵蚀民主所需的公开讨论 → 数据过载与误报使大规模监控在操作上适得其反 → 定向且经司法授权的监控才与安全需求相称
  - 适用题型：opinion
  - 来源样本：`B8-OP-004`（8）
  - 高分搭配：`mass surveillance`、`targeted surveillance`

- **[GOV-25] 观点：缓解公交涨价压力可向学生、老人与低收入者提供折扣或补贴票，并转向电动、太阳能等更省钱的环保车辆，长期运营与维护成本更低。**（倾向：支持）
  - 展开：票价上涨挤压城市居民的月度预算 → 面向脆弱群体的定向补贴缓解压力 → 更环保的车辆长期运营维护更便宜，兼顾减排与降本
  - 适用题型：report
  - 来源样本：`B8-REP-030`（8）
  - 高分搭配：`discounted or subsidized tickets`、`low income backgrounds`
