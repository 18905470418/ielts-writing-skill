# IELTS Writing Scorer

一个用于 IELTS Writing Task 2（雅思大作文）的评分与教学 Skill，不适用于 Task 1 小作文。

评分校准依据是 1490 篇标注范文（Band 6 / 6.5 / 7 / 7.5 / 8 / 8.5 / 9）蒸馏出的六层知识资产。一次完整输出会给出四维评分、模块化反馈、个性化 8+ 范文和逐句拆解练习。

## 功能

### 校准评分

给出 TR、CC、LR、GRA 四项分数、总分、实际字数和一句话总评。每项分数由规则命中情况和同题型相邻档锚点比对推出，输出中引用具体规则条目（如 `L1-TR-3.2`）与锚点样本 id，不接受没有依据的整体感觉分。四项独立评分，模块之间互不牵连，LR 或 GRA 弱不会压低 TR；每个模块先写特征描述，再给分。

评分前先做边界检查：字数少于 240 词、疑似模板套作、完全跑题会先标注，并给出相应的分数上限或低档处理。

### 模块化反馈

反馈按提分收益排序，先给优先修复清单，再逐模块展开。

- 优先修复清单：封顶性问题排最前，其次是全文性的系统问题，最后是局部错误；每项注明修复后预计影响哪个模块、多少分。
- TR 思路重构：检查立场与论证链，给出段落级改写方案，并从观点库补 2 到 3 条用户没想到的高分角度。
- CC 逻辑诊断：画出每段功能与全文论证链，定位跳跃、循环论证、论点与例证脱节、衔接词机械化、指代断裂等问题，给「原文 → 修正 → 说明」示范。
- LR 词汇修正：列出搭配错误、中式直译、语域不当等问题并逐条修正，再按主题补 8 到 12 个高分词伙，每个词伙配一句结合本题语境的例句。
- GRA 语法清单：穷尽全文语法错误，逐条修正并解析；另挑 3 到 5 个语法正确但表达平庸的句子，各给「稳妥版 + 出彩版」两种升级。

### 范文教学

- 原文逐句对照：逐句对照原文与范文，标注每处改动的原因和所属模块；写对的句子也会列出并标「保留」。
- 个性化 8+ 范文：270 到 300 词，保留用户立场与可用论点，只升级表达。
- 逐句教学卡：范文每一句一张卡，包含原句、功能、句式骨架、中文回译提示、仿写练习、自检要点。
- 三级练习：句式仿写、中译英回译、段落重组，由局部到整体。
- 拼装指南：从主题句、段落填充、衔接检查到成文自查的五步流程。

### 语言规范（人味化）

批改文件的讲解文字按「温柔、具体、有下文」输出：每条判断落到「句证 → 原因 → 改法 → 效果」，错误清单后有归纳与下一步练法；中文讲解去除对偶升格、金句收尾、假深刻措辞等机器腔，英文范文同样过滤 AI 写作套路与万能模板句。细则见 `references/humanizer-rules.md`（适配自 Humanizer v3.1.0）。

### 输出格式

最终结果是一个 Markdown 文件：默认写入用户当前工作目录，文件名「雅思写作批改-<主题关键词>-<日期>.md」；文件内不使用任何表格，评分卡、优先修复清单、词汇与语法清单、原文对照一律用列表或分段呈现；对话里只留文件位置与简短导语。

## 工作流

```
输入：用户作文 + 题目
│
├─ 0. 边界情形检查：字数 <240、疑似模板套作、完全跑题；无题目则拒绝硬评
├─ 1. 审题前置：解析题目 → 检索 question-bank → 识别题型与主题
├─ 2. 四模块独立诊断：TR / CC / LR / GRA，先特征描述再给分
├─ 3. 锚点比对定分：与同题型相邻两档锚点对比，确认档位归属
├─ 4. 总分合成：四项平均，按官方规则取整（.25 → .5，.75 → 下一档）
├─ 5. 模块化反馈：优先修复清单 → TR → CC → LR → GRA
├─ 6. 范文教学：原文逐句对照 → 个性化 8+ 范文 → 逐句教学卡 → 三级练习 → 拼装指南
└─ 7. 人味化校对：按 references/humanizer-rules.md 校对讲解文字与英文范文
```

输出顺序固定为：边界情形标注 → 评分卡 → 优先修复清单 → 四模块反馈 → 原文逐句对照 → 范文 → 教学卡 → 练习。组装输出前先执行第 7 步人味化校对，全部内容写入同一个 Markdown 文件。

## 使用

提交 Task 2 作文并要求打分、批改、提分诊断、高分范文或写作练习时触发。建议把题目和作文一起提交；没有题目时 TR 无法评分，Skill 会先要求补充题目，不做硬评。讲解和反馈用中文，英文只出现在原句、修正句、范文与词伙中。批改结果写入一个 Markdown 文件（默认在用户当前工作目录，文件名「雅思写作批改-<主题>-<日期>.md」），文件内不含表格；对话里只给文件位置与简短导语。

示例：

```text
题目：Some people believe that university education should be free for everyone. To what extent do you agree or disagree?

作文：<粘贴你的 Task 2 作文>

请打分，并告诉我最值得优先修改的地方。
```

## 知识资产

| 层 | 文件 | 内容 | 规模 |
|---|---|---|---|
| L1 评分规则库 | `references/band-rules.md` | TR/CC/LR/GRA × 7 档判别规则 + 6 组相邻档 Delta + 半分档 | 全文必读 |
| L2 锚点范文库 | `references/anchors/<题型>.md` | 每「分数 × 题型」2 到 3 篇代表作 + 逐项评语 | 5 个题型文件 |
| L3 错误模式库 | `references/error-patterns.md` | 高频失分模式 + 母语负迁移标签 | 全文必读 |
| L4 语言资产库 | `references/language-assets.md` | 高分句式、衔接、论证展开套路 | 按题型/主题检索 |
| L5 观点库 | `references/viewpoint-bank/` | 8+ 样本的论点与展开链条 | 248 条 / 10 主题 |
| L6 主题词库 | `references/topic-vocab/` | 8+ 样本高频词伙 + 原文例句 | 485 条 / 10 主题 |
| 题目解析库 | `references/question-bank.md` | 关键词拆解、隐含限定、审题失误、双边观点池 | 56 个高频题簇 |

观点和词伙都带库内编号与来源样本 id；库里没有对应主题时，Skill 会输出「暂未收录」，不编造内容。

## 纪律条款

1. 分数必须可追溯：每项分数由规则命中情况和锚点比对推出，不允许没有依据的整体感觉分。
2. 四项独立评分：模块之间互不牵连，比如不得因为 LR 弱就压低 TR。
3. 诊断先于分数：每个模块先写特征描述，再给分。
4. 禁止编造库内容：观点、词伙、锚点、审题要点一律来自 references/ 并注明编号。
5. 修改保持原意：范文重写与句式升级只升级表达，不替换用户观点。

## 安装

把 Skill 目录复制到 Codex 的 skills 目录：

```powershell
Copy-Item -Recurse .\ielts-writing-scorer $HOME\.codex\skills\
```

其他支持 Skill 的环境，把 `ielts-writing-scorer/` 当作 Skill 根目录即可。Skill 名称在 `SKILL.md` 的 frontmatter 中定义为 `ielts-writing-scorer`。

## 数据来源与限制

- 知识资产蒸馏自 1490 篇公开标注范文的 7 个分数档（训练集 1193 篇）。
- 分数标签复制自来源页面，本 Skill 不对来源语料重新打分。
- 8.5 档与部分半分档来源以自动评分为主；L2 锚点与 L1 规则对这类来源从严使用。
- references/ 中的来源样本 id（如 `B8-DIS-001`）用于溯源标注；原始语料不随本 Skill 发布。
